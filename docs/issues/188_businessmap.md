## Description

**Category:** new-service

Businessmap is an EU-based project and portfolio management platform that is focused on enterprise agility. Businessmap combines planning with execution in a single platform and provides PMO leaders with an unmatched visibility across project and OKRs progress in their organization. Businessmap has flexible Kanban and Scrum boards for workflow tracking and is a European alternative to Jira.
