## Description

**Category:** new-service

Leviia Next is a European collaborative platform operated under French jurisdiction and based on the open-source Nextcloud project. It provides file storage, sharing, synchronization, and collaborative tools for organizations.

The service can replace non-EU collaboration suites such as Microsoft 365 (OneDrive, SharePoint) and Google Workspace, while ensuring data hosting and processing exclusively in France, under EU data protection regulations.

Leviia Next is operated by a French provider on infrastructure located entirely in France. The service complies with GDPR requirements and runs on infrastructure certified ISO 27001 and HDS.
